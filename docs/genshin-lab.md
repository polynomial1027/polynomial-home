# 原神专业知识测试窗口

管理员入口：首页「测试功能区」、个人空间同级导航「测试功能区」，或 `/labs/`。
页面、JS、CSS 与 `/api/admin/labs/*` 均在服务端检查登录管理员，返回 `no-store`。
尚未发布到正式应用工具列表。

## 数据与证据

旧 ChatGPT 对话只提供了消息占位符，没有可读取的附件正文。**没有导入旧手册，也没有全量 7.1 数据库**。
窗口可以导入 MD/TXT/JSON/CSV 文本，按标题和版本保存；每份250KB、总计2MB、最多40份。较大文件需分卷。
导入资料是管理员提供的待核验数据，不会自动提升为已验证事实。不是完整表格数据库或全量战斗模拟器。
检索按问题词匹配选择最多6个文本片段；不保证遍历全手册。角色/武器/怪物/圣遗物的缺失数据必须补充。

内置基础机制摘要，来源为 KQM 伤害公式、元素量框架、ICD 与充能机制。不能替代逐角色、逐击、逐等级表。
联网调用 DeepSeek Search，过滤返回 URL，只接受 HTTPS、无凭据、标准端口且域名在白名单的结果。
搜索请求限定 KQM 与官方原神站点，结果还可接受官方 Wiki 站点。只使用正文；最多补抓一篇白名单正文，摘要不作为依据。
网页版本仍需核验；网页和导入内容仅作为资料，不作为系统指令。

AI 输出必须为结构化事实、来源ID与逐字引文，服务器拦截不存在的来源与不匹配的引文。
**这是引用存在性校验，不是语义证明**：仍可能发生解读错误、过期资料与引用不能支持结论的问题，UI 明示需复核。
不会宣称严格保证全部回答正确。没有可引用证据时不显示无来源结论。
不执行模型代码、模型算式或模型提供的 URL，也不使用模型记忆填补缺失数值。
用户可勾选将完整面板附带到问答：服务器先计算，模型只能引用该次确定性计算结果，不自行选择计算参数。

## 数学计算

服务器支持完整面板下单次攻击力倍率伤害、期望暴击、分段抗性、防御、条件蒸发/融化以及换装对比。
输入必须是换装前后完整战斗面板，不是单件圣遗物词条。返回输入、乘区和公式供复算。
反应必须由用户依据附着量、ICD、时间序列确认。未实现自动元素附着、衰减、产球/充能、循环、月反应或特殊倍率模拟。
计算接口不调用 API。

## 测试总预算

复用服务端 `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` 与现有 AI 总开关，不向浏览器暴露密钥。
默认全管理员共享累计100,000 token，不限制外部请求次数；无日/月自动重置。旧版6次/30,000预算自动迁移并记录用户本次授权，保留已有用量。
每次 Search、Fetch、Chat 均在发出前持久记账，失败也占次数。搜索/抓取按请求计费，不计入token数字。
聊天使用保守的 UTF-8 输入字节+1024+最大输出token预留，成功时按供应商实际token结算并释放多余预留；失败或缺失usage则保留预留。
Chat 使用测试区独立的累计100,000 token预算，不受主助手的日/月请求和token限额重复拦截；保留原有AI用量明细并标记independentBudget。主助手限额统计排除独立预算记录，不改变其设置。
不自动重试。预算不足返回429，不调用上游。上游成功但回答格式错误仍记账。
只能由管理员勾选明确确认，增加累计上限；不会清空历史用量。扩大上限会留下审计事件。

账本与资料保存在数据目录 `genshin-lab.json`（临时写入后原子替换），含调用类型、时刻、预留/实际token、结果状态。
测试记录在窗口中显示最近50条，文件保留完整记录；站内备份服务同步归档此文件，恢复验证包含其完整性。

官方接口说明：<https://api-docs.deepseek.com/guides/search/>。
当前普通 Chat Completions 调用不会自动搜索，本功能显式调用 `/v1/tools/search` 与 `/v1/tools/fetch`。
联网费用独立于聊天token；同一密钥的实际端点可用性需要部署环境验证。

## 验证

`node --test tests/genshin-lab.test.js` 覆盖公式、管理员权限、来源过滤、持久化、引文拒绝、失败计费与额度停止。
`playwright test tests/browser/genshin-lab.spec.js` 使用隔离数据与模拟供应商，不消耗真实资源。

## 真实API对照测试

`scripts/test-genshin-live.js` 通过运行中的管理员接口依次提问8个标准题：攻击力换装、蒸发、融化、负抗性、暴击率上限、ICD、充能与西风、缺少角色数据。
数值标准是独立手算常量，不调用生产计算器生成预期。模型必须引用服务器结果才判数值题初筛通过；机制题自动关键词初筛仍需人工逐条读原文与回答。
测试使用同一份累计100,000 token账本；遇到HTTP错误或额度不足立即停止，不重试，不自动增加上限。
需要以管理员会话设置 `GENSHIN_TEST_COOKIE`（不应输出或提交此值）；`GENSHIN_TEST_BASE` 指定服务地址，`GENSHIN_TEST_REPORT` 指定报告路径。
无真实API测试报告时，不能将模拟测试结果标为真实模型准确率。

服务器上也可执行 `POLYNOMIAL_DATA_DIR=/var/lib/polynomial-server node scripts/test-genshin-live.js --use-local-admin-session`。
此显式选项只读数据库中的有效管理员会话，在回环地址访问原有鉴权接口；不会创建会话、修改权限或显示凭据。
需要管理员此前已在网站登录。报告默认保存 `/tmp/genshin-live-report.json`，含实际回答与独立预期，全部真实调用走线上预算与用量账本。
