## 结果与预算

8 个标准题取得有效回答，核对了 5 道数值题、2 道机制题、1 道数据不足题。随后针对暴击率上限与充能题复测，均符合本次预期。

累计真实调用：14 次聊天、3 次搜索，共17次外部请求。累计实际聊天 token 为 **29,154 / 100,000**，剩余 **70,846**。搜索按供应商请求另行计费，不伪装为 token。没有请求次数上限，不自动重置或增加 token 总上限。成功聊天按供应商实际 token 结算，失败或未取得 usage 时保留预留额。

所有真实测试通过线上管理员 API 运行，使用同一份持久账本，包含修复前的调用。密钥和登录会话未写入报告。数据目录的 `genshin-lab.json` 保存预算与调用记录；AI 审计明细保存提问、上下文、实际回答和供应商用量。测试预算独立于主助手日/月限额，原主助手额度设置不变。

## 数值题：独立标准与实际答案

共同基准是单次攻击力倍率伤害：总攻击力2000、技能倍率200%、增伤50%、暴击率50%、暴伤100%、精通0、角色与敌人均90级、敌人抗性10%、减防和无视防御均0、不触发反应。防御乘区0.5，抗性乘区0.9，期望暴击乘区1.5，基准伤害为4050。

标准答案为预先独立手算的常量，不由生产计算函数生成。实际答案同时核对服务器数值和 AI 是否在回答中明确给出相应伤害，不能仅因服务器算对就判 AI 通过。

| 确认本次火伤蒸发，精通0 | 4050 → 6075，提升50% | 6075，提升50% | 一致 |

## 机制题和拒答题

- ICD：回答元素伤害命中不等于每击附着；说明标准规则是2.5秒或每3次命中，计数触发不重置计时、计时触发重置计数，并保留技能例外。联网取得了 [KQM ICD 正文](https://library.keqingmains.com/combat-mechanics/internal-cooldown)，核心结论与原文一致。
- 充能与西风：回答充能效率不增加产球数，西风被动成功触发产生3个无色微粒，直接固定回能不受充能效率加成。联网取得了 [KQM 充能正文](https://library.keqingmains.com/combat-mechanics/energy)，核心结论与原文一致。
- 数据不足：询问未导入的「维斯娜7.1版本90级基础攻击力、逐击附着、ICD组、产球数、最佳圣遗物」时，事实结论列表为空，明确列出缺失资料，没有编造角色表或给出确定配装。

自动关键词筛选只用于初筛；以上实际回答另经逐条核对。这个小样本不能推导出所有游戏问题的准确率。

## 真实测试发现的问题及修复

首轮4次聊天共5198 token后，第五题被通用助手额度拦截；同轮蒸发/融化回答还错误声称缺少面板，没有给出充分数值答案。因此首轮不能当作完整通过。

修复后：测试区使用用户授权的独立100000 token预算；AI 同时收到完整输入、反应确认状态、计算乘区和结果。改进了评估，要求 AI 确实报告数值答案，随后完成8题复测。

还发现了过度追问和误称伤害表单可计算充能的问题，修正能力说明后，对暴击率与充能题再次真实复测，两题均正确回答且缺失信息列表为空。既有用量与审计记录没有清零。
