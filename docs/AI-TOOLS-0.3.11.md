## 已实现

- 通用对话、摘要、资料问答、翻译、写作、代码审阅、会议纪要、学习、计划，共九种工具。新会话保存所选提示词快照，修改模板不会改变已经开始的会话。
- 新建、重命名、置顶、搜索、归档、恢复、JSON 导出与确认删除。浏览器下载导出文件，原生客户端可复制导出内容。每个账号最多 100 个会话、20 个自定义模板。
- 旧聊天自动归入本人“历史对话”；每个会话有自己的草稿和消息上下文。同一会话发送时锁定，避免重复提交；不同会话仍共用账号与全站预算。
- 上下文取本会话最近八条消息，最多 12,000 字符。单会话最多保留 500 条消息，账号最多 2,000 条；达到上限时先提示导出并删除，不静默丢弃历史。已有超限旧数据仍保留。
- 文本附件支持 txt、md、csv、json 和常见代码文件，要求 UTF-8、最多 8,000 字符与 32 KiB。仅发送时提交；读取不调用模型，刷新后需要重新选取文件。
- 低峰队列记录原会话和附件，执行时复查权限与预算。完成后回到原会话；存在待执行任务或正在发送时阻止归档与删除。
- 管理员审计显示会话、工具和文件名，实际上下文与回复纳入原有记录与内容保留期限。删除会话不删除计费审计。
- 计划工具可按原有结构写入本人的计划与提醒，遵循权限。其他工具默认只生成文字；邮件回复是草稿，代码审阅不执行代码。服务器管家继续仅管理员可见。

## 范围

使用已经配置的 DeepSeek API 与统一预算，不需要额外供应商密钥。未新增网页搜索、PDF/图片解析、语音、任意 shell 或外部 MCP 插件。资料按不可信参考内容处理；模型不能通过附件取得额外账号权限。多设备修改采用版本校验；附件与上下文同样计入预算。

## 验证与回退

使用模拟模型响应验证上下文隔离、并发预算、队列归属和权限；浏览器覆盖桌面及手机操作、草稿、模板、附件、归档、导出和跨账号拒绝。正式发布前运行后端、静态与浏览器检查。

回退分支 `codex/before-v0311-ai` 保留 0.3.10；部署另存完整数据备份。旧代码不理解新会话边界，回退前应导出新会话并停用 AI，再恢复匹配的代码与发布前数据备份；只回退代码会把本人的各会话视为同一段历史。
