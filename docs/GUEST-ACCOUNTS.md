# 访客账户

## 创建与调整

在管理后台 → 账号管理 → 新建账号中选择“访客（隔离体验）”，设置用户名与密码。现有账户也可通过编辑账号切换。访客没有公开自助注册入口。请用独立访客账号向他人提供体验。

| 功能 | 访客范围 |
| --- | --- |
| AI | 对话、摘要、翻译、写作、学习和计划工具；不能使用自定义提示模板、代码和资料问答等扩展工具 |
| AI 限额 | 每天最多 5 次、每月最多 30 次；每天 10000 / 每月 50000 Token；单次输出最多 512 Token |
| 日程 | 本人日历、计划与提醒，其他账户无法读写 |
| 云盘 | 本人私有文件，最多 32 MB；不能公开或分享 |
| 游戏与工具 | 普通休闲小游戏与原神计算器；围棋不开放 |
| 聊天与通讯 | 不开放，不进入其他用户的聊天与分享对象列表 |
| 管理与课程容器 | 不开放 |

管理员可关闭允许的功能、缩小云盘额度或降低个人 AI 限额，不能在访客角色下开启禁止的功能或超过体验上限。需要更多权限时改为普通用户。AI 仍需服务已配置并启用，同时受全站额度、预算和并发限制；用完后拒绝调用，不自动购买额度。次数和 Token 按现有北京时间日/月计量规则重置；接口失败的预留消耗继续遵循全站策略。

## 账户转换

普通用户改为访客后：

- 所有旧登录及聊天、围棋连接失效，需要重新登录。
- 取消聊天成员资格与待处理围棋邀请。
- 撤销与该账户有关的网盘分享，所拥有文件转为私有。
- 超过新云盘额度的已有文件保留，可下载、删除，不能继续上传。
- 历史数据保留用于本人符合权限的使用及管理员审计；不会自动清除旧对话或扩大访问权限。

重新改为普通用户不会恢复已撤销的分享、成员资格或原有权限组合，请管理员重新配置。

## 隔离含义

访客禁止通过页面、HTTP API 或聊天/围棋 WebSocket 与正式用户互动；本人 AI、日程和网盘按账户归属检查。管理员仍按原有管理权限查看账户及审计数据。公开站点内容、客户端安装包、公告和独立计算器仍可访问，不属于共享网盘访问权限。

自动化回归使用临时数据库与模拟模型，不修改线上账户，不消耗真实 AI 额度。Android 通知的系统实际显示仍需要真机验证。

## 回退

部署前自动保存全量数据备份，代码保留 codex/before-v0314-guests。旧版本没有访客隔离策略：回退前必须停用所有访客账户，或在停服后恢复部署前数据。不要仅切回旧代码而保留启用的访客账户。
